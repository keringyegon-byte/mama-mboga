# Mama Mboga

A small online kiosk inspired by the neighbourhood *mama mboga* in Kenya. Browse fresh produce priced in KSh, add it to a cart, and (coming soon) send the order on WhatsApp.

Built with plain HTML, CSS and JavaScript. No frameworks.

## Run locally
Open the folder in VS Code and start it with the Live Server extension.
